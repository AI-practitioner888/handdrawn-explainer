# Story and evidence

The visual style is a fixed warm paper board with restrained ink/accent colors, deliberate whitespace, and an accumulating explanation. Much of a strong whiteboard reference's appeal comes from hierarchy and synchronizing a reveal with the phrase that explains it. A 20-second piece has room for a small argument, not a complete lecture.

Choose the most useful narrative structure:

| Request | Structure | Visual choices |
|---|---|---|
| Elementary lesson | Question → diagram/example → takeaway | One concept per beat, reusable objects |
| Language lesson | Sentence → wrong choice → correction → rule | Separate word IDs so an eraser can replace one token |
| History | Situation → turning point → consequence | Date/location labels; timeline or causal arrows |
| News | Verified event → context → implication/uncertainty | Distinguish a quote, announced plan, completed action, and inference |
| Comparison | Shared question → alternatives → decisive difference | Stable left/right columns, consistent scale |

Write narration before allocating locked actions. Keep a natural speech pace; draw a prepared diagram while explaining it, then leave a short hold. A useful 20-second planning starting point is 2 seconds for the question, 12–14 for the explanation, and the remainder for the conclusion and hold. Adjust to the content and voice. Avoid enforcing an arbitrary character count; actual TTS/recorded timing decides fit.

Use source URLs and claim notes in `sources`, for example `{title,url,eventDate,checkedAt,claims:[...]}`. Preserve the source's distinction between proposed and enacted events. The animation should not make an unsupported assertion simply because it is visually convenient. Identify editorial inference in narration/caption when consequential. Stable basic mathematical concepts do not need a fabricated news hook or unnecessary browsing.

Keep one major area active. Finish related objects before changing the drawing focus. A picture should remove explanatory work: depict containment, comparison, sequence, or consequence rather than an unrelated decorative object. Labels can clarify a portrait, but do not use labels to conceal a poor likeness.

Use captions sparingly when board text already carries the same phrase. A spoken explanation, diagram label, and full transcript shown simultaneously can overwhelm a small frame. Caption and board text should each have a reserved area.
